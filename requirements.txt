# NOTE: every dependency is pinned exactly.
#
# These ranges used to float. Combined with `--no-cache-dir` in
# serverless.yml, every CI run re-resolved to whatever was newest, so the
# deployment package grew without a single line of code changing — until
# 2026-10-11, when it crossed Lambda's hard 250 MB unzipped limit and
# CloudFormation rolled back a production deploy. A build you cannot
# reproduce is a build you cannot diagnose.
#
# The pins below are the versions resolved by the last SUCCESSFUL production
# deploy, i.e. what production is running today — chosen over "latest" so
# this change alters package size and nothing else. Drift had already carried
# openai from the 1.12 floor to 3.29; the test suite mocks OpenAI, so it would
# not have caught a breaking change there.
#
# Bump deliberately, one dependency at a time, with a staging deploy.
